Skypro Music — это веб-приложение для прослушивания музыки, разработанное на Next.js. Проект представляет собой музыкальный стриминговый сервис с возможностью просмотра треков, фильтрации по жанрам, исполнителям и годам, а также работы с подборками.
 Функциональность
 Для всех пользователей
 Просмотр всех треков
Фильтрация треков по:
Исполнителям
Жанрам
Годам выпуска
Поиск треков по названию, исполнителю и альбому (от 1 до 3 символов)
Просмотр подборок:
Плейлист дня
100 танцевальных хитов
Инди-заряд
Для авторизованных пользователей
Доступ к разделу "Мои треки"

🚀 Установка и запуск
Предварительные требования
Node.js 18+

npm или yarn

Установка зависимостей
bash
npm install
# или
yarn install
Запуск в режиме разработки
bash
npm run dev
# или
yarn dev
Приложение будет доступно по адресу: http://localhost:3000

Сборка для продакшена
bash
npm run build
npm start
🧪 Тестирование
Проект покрыт модульными тестами с использованием Jest и React Testing Library.

Запуск тестов
bash
# Все тесты
npm test

# Режим наблюдения
npm test -- --watch

# Покрытие кода
npm test -- --coverage

# Конкретный компонент
npm test -- app/components/Filter/Filter.test.tsx
npm test -- app/components/Navigation/Navigation.test.tsx
npm test -- app/components/Sidebar/Sidebar.test.tsx
Покрытие тестами
 Filter — фильтрация треков, работа с попапами
 Navigation — навигационное меню, авторизация
 Sidebar — подборки, мобильное поведение
